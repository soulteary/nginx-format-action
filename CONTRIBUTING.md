# Contributing

Issues and pull requests are welcome.

1. Create a focused branch from `main`.
2. Run `npm run check` and `npm test`.
3. Add or update tests for behavior changes.
4. Keep `action.yml`, the English README, and the Chinese README consistent when inputs or outputs change.

The action intentionally has no runtime npm dependencies. Prefer Node.js built-ins unless a dependency provides a clear security or maintenance benefit.
